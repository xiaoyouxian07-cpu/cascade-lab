# Security

Cascade Lab accepts numeric configuration, never target addresses or executable code. It makes no simulated requests to real services. Browser imports are limited to 32 KB and validated against known settings. The development server binds to loopback and serves an explicit asset allowlist.

Do not include credentials, production logs, or personal data in reports. If you find a security issue, use the repository's private vulnerability reporting feature when enabled. Otherwise contact the maintainer privately through their GitHub profile before publishing exploit details.

Version 1.x is the currently maintained line. Configuration links are not encrypted; anyone with the link can see the simulation parameters. There is no promise that a simulation is an accurate prediction of production behavior.
