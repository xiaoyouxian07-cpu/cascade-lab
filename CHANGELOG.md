# Changelog

## 1.0.0 — 2026-11-17

- Deterministic 25 ms queueing model with Poisson arrivals and independent policy randomness.
- Five scenarios and paired browser comparisons.
- Retry policies, bounded queues, worker pools, attempt timeouts, token-bucket admission, and a shared circuit breaker.
- Replay, pressure chart, client outcome accounting, and explicit successful-client latency.
- English/Chinese UI, experiment links, config import/export, and Markdown reports.
- Dependency-free Node CLI and automated invariant tests.
- Documented model limits, contribution guide, issue templates, and CI/Pages workflows.
